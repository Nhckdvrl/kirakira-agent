## 数据与方法

使用固定 LongMemEval-S revision，各类型按 ID 摘要选 6 题，共 36 题，其中自然抽中 3 道 abstention。
本地 BGE-small-en-v1.5/ONNX 产生 384 维向量；每题独立图，实际学习 **8,791 个完整消息对**。
原始消息均落库，**141 条未配对消息**不进入各检索组的完整消息对投影。

四组使用相同历史、向量、最多 10 对/24,000 字符预算，并回源到相同格式的完整原文。
答案标注只用于 judge 和事后覆盖诊断，不进入普通 reader 或索引。
日期排序、未来于问题日期的给定 haystack、投影与固定 ID 规则见[完整协议](../memory-evaluation.md)。

两轮分别保存四组回答与 oracle 对照，共 **360 组 reader/judge 实验、720 次逻辑生成调用**。
这是 36 道题的重复与对照，不是 360 道独立题，也不是完整 500 题成绩。

## 初始轮次原样保留

初始轮次输出上限为 4,096，发送了 `thinking=false`。核对
[Step5 官方模型说明](https://platform.stepfun.com/docs/zh/guides/models/step-5-preview)
后确认，文档支持的推理控制是 `reasoning_effort`；该初始参数不能证明关闭了推理。
因此接入改为显式原生参数，并统一配置复跑，未覆盖初始结果。

| 方案 | 初始轮 | 原生配置复跑 |
| --- | ---: | ---: |
| 无记忆 | 3/36 | 3/36 |
| Dense | 28/36 | 28/36 |
| v1 | 29/36 | 27/36 |
| Akasha2 | 25/36 | 27/36 |
| Oracle | 31/36 | 33/36 |

初始 v1 有一次 judge 长度截断（`38146c39`），计为错误，未重试到成功后替换。
该失败响应的 usage 未被当时的 verifier 保留；现已让截断错误携带响应，后续可保存用量和正文。
两轮控制参数不同，不能将分数变化解释为单一改动的因果效果，也不能把两轮当相同配置的置信度重复。

质量实验已保存响应的 usage 合计为输入 **1,095,754**、输出 **182,126** token。
这些数不含上述缺失响应及功能验证的全部用量，也不是账户计费账单。

## 错误告诉我们什么

**图 readout 会漏掉比较所需的另一段经历。** `a11281a2` 的增长比较、`1192316e` 的准备加通勤时间、
`gpt4_45189cb4` 的多个事件排序，都出现部分来源缺失。只找到一个相关 session 不代表拿到了完整答案。
因此本报告同时记录 session recall 与精确到标注消息对的覆盖；后者更能解释这一类错误。

**拿到来源也仍可能答错。** v1 和 Dense 的 session recall 均约 98.5%，回答正确率仍只有 75–77.8%。
上下文噪声、选中错误更新、生成和 judge 都是变量，不能把回答分数直接当图算法的纯质量。

**Oracle 也不是数学上界。** `352ab8bd` 的标注证据不在完整消息对投影中；
`57f827a0` 和 `0edc2aef` 是个性化建议，严格“仅按原文回答”的 reader 会拒绝将历史偏好用于新场景。
后续应预先固定适合个性化任务的 reader，再在新样本上验证；不据此事后改写本轮成绩。

**真实语料暴露了工程问题。** v1 把同时间戳 turn 的文本序号当顺序，会在两位数序号时误报乱序。
已改为遵循持久 publication 位置，并通过 12 个同时间戳 turn 的线上/离线重建一致性回归。
另修正了 verifier 对异步关闭、receipt ACK 与兴趣 feedback、ACK 返回顺序的错误预期。
这些适配期失败记录在 manifest；正式四组结果没有删题、换题或只保留成功样本。

## 当前决策

保留 v1、提供显式 opt-in 的 Akasha2，不自动迁移历史或切换默认。
新增 checkpoint/消费绑定、原文校验、查询不学习与故障停止合同值得保留，实际质量提升仍需证据。
下一步优先验证完整经历覆盖、Dense 与图的互补消融、个性化 reader 和中文/更多 embedding；
这些应使用预先固定的新协议，不能继续在这 36 道题上调参后宣称泛化提升。

本轮只有一个英文 embedding、固定小样本、同模型 judge，类型比例也不等于原数据集比例。
不据此宣称全面对齐上游、全量榜单成绩或统计显著优势。
