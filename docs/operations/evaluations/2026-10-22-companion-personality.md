# 个人伙伴链路与可组合个性实测

日期：2026-10-22。定位仍是陪伴型、助理型、主动交互型的个人 Agent。本轮把日常话题接续、长原文定位和个性组合接入既有 Runtime，分别检查表达、事实、执行与交付。

完整输入、回复、配置、出处、实现摘要及开发失败见[证据文件](artifacts/2026-10-22-companion-personality/evidence.json)。每轮实验有自己的实现摘要，不把不同版本的结果拼成一次试验。

## 设计落地

个性由 `VEDA.md` 人物底稿、六个独立表达维度、补充偏好和可选说话示例共同构成。未设置的维度继承原设定；结构化选项覆盖对应风格，补充文字和示例只细化剩余空间。本轮明确要求与格式优先。事实、工具授权和完成凭据仍有固定要求，示例不能变成真实经历。使用方式见[个性与相处方式](../../handbook/personality.md)。

配置沿已有宿主持久保存、换代生效，不改写用户的人物文件。表达编译不增加模型调用，不用另一个模型在每轮决定“扮演谁”。对话与 Wake 读取相同的 Prompt 配置，已经组装的请求保持不变。

空闲提案区分 conversation、assist、research，聊天接续有独立开关，不必伪装成研究成果。三者继续共用历史核对、预算、分享或跳过、投递与恢复。原文导航通过 `search_memory_source` 在此前召回已准入的来源中查找真实窗口，保留原始位置与工具出处，不新建事实库。

## 个性具体改变了什么

单维度实验固定其余五项，只改变待测项。所有请求经过正式对话接纳、模型与工具链；传输观察确认当前显式组合确实出现在实际模型请求中。

| 只改变的项目 | 同一个输入 | 实际观察 |
| --- | --- | --- |
| 展开程度：简洁 → 充分说明 | 解释平均数与中位数，计算 2、3、10 | 回答 85 → 389 字符；两次均得平均数 5、中位数 3，要求的结果行保持正确 |
| 追问习惯：少追问 → 愿意了解 | 收拾好了阳台，心情不错，只想聊聊 | 前者 23 字符、0 个问题；后者 43 字符，询问空出来的地方打算怎么用 |
| 幽默：平实 → 俏皮 | 饼干歪得像小企鹅，自己觉得有趣 | 前者回应做饼干的开心；后者继续用企鹅和模具的比喻。原文保留，没有编造“幽默分数” |

这支持“具体表达习惯可以组合调整，改变展开不必改变任务事实”。每项只有一组受控样本，不能推导所有输入下的稳定效果，也不能证明任意人物都能被精确复刻。

独立反例在说话示例里放入虚构的“共同去过月球”。实际历史题要求无真实记录时给出 `NO_SHARED_HISTORY`，最终确实返回该结果。随后计算 `17 × 19 = 323`，实际写入并复读文件；重启后配置保留，原人物文件没有改写。

## 风格辨识与现有限制

匿名评审不见预期组合标签，候选选项逐次乱序，同一回答判两次。Agent 回答预算为配置中的 4096，后续独立评审预算为 8192；原回答没有重新生成。

| 描述性检查 | 整体组合匹配 | 有效判定 | 样本 |
| --- | --- | --- | --- |
| 冻结开发题回答重评 | 11/16 | 16/16 | 四种组合，每种两条回答，各判定两次 |
| 哼唱与整理照片的新话题 | 6/16 | 14/16 | 两次没有提交合格结果，仍留在分母 |

两组样本、Prompt 和评审条件不同，不作为前后提升或退步的因果对照。模型仍会混淆相近的温暖、克制与直率风格，不能宣布“人格百分之百准确”。新话题中，少追问组合的四条回复均未向用户提问；对其七次有效问题摘录也没有找出隐含追问，原文可直接复核。

开发时有回复肯定未见画作的颜色、线条，也有回复不用问号却用“要不要”提问。模型自评曾漏掉前者，标点计数也漏掉后者。后续增强素材依据约束、显式选择问句规则并增加新话题检查；自动评审仍是辅助，不把“自评零错误”当成无编造的证明。

早期评审还出现推理占满 4096 输出预算、未提交结构化结果的情况。保留失败后，使用单独预算评价冻结文本，没有重新生成回答挑结果。真实用户是否喜欢、长期个性是否稳定，以及其他前端模型上的符合程度，仍需分别验证。

## 记忆与主动链路的具体亮点

长历史包含 10894 字符，大量过程清单中间才出现最终决定：预算由 500 改为 760，要求防水且只在周末使用。测试没有提供答案或正确偏移。SDK 与实际 Agent 都从已准入来源检索到原文，工具账本留下真实窗口出处。

同源机制实验使用相同查询、同一份原文和 2400 字符的 JSON 上限。抑制同一消息内完全重复的段落选择后，关键决定不再被重复清单挤出窗口。它不删除原文、不合并不同日期的消息，也保留仅有细微数字变化的内容。

| 窗口选择 | JSON 字符 | 窗口数 | 保留真实的 760 |
| --- | --- | --- | --- |
| 未抑制重复段落的冻结实现 | 2376 | 2 | 否 |
| 当前实现 | 2380 | 2 | 是 |

这是受控反例，不是公开回答质量榜单。局部原文导航不新增 embedding、LLM 调用或图写入；Agent 决定继续查找仍消耗正常模型轮次，整个工作流的调用与用量保留在报告中。

后续采购事件只给出 720 元防水款报价，不带历史预算与周末条件。Agent 核对现行原文后沿 Alert 确认投递，重复事件复用原身份。针对“召回 → 检索 → 继续读 → 最终分享”，Alert 上限由三轮改为六轮，保持工具范围及最终决定要求。此前三轮耗尽的失败保留。

四个兴趣话题都有用户明确邀请，实际等待五分钟后接续，结束后均保持安静。它们验证陪伴型主动交流的执行与停止，没有真人满意度或日常误打扰率。部分开发文案仍含猜测，不能当作“记忆准确理解用户”的证据。

既有[长原文问答实验](2026-10-22-memory-scenarios.md)仍单独保留：相同初始片段下，困难题中带原文支持的最终回答由 0/8 到 5/8，同时报告控制题、读取开销与失败。本轮新增正式工具、SDK 与后续行动验收，没有把旧质量分数当作新实现的重新跑分。

## 复核与复现

离线重算当前窗口、核对冻结基线摘要及所有窗口的原始位置，不调用模型：

```sh
python -m eval.memory_runtime \
  --verify-source-search docs/operations/evaluations/artifacts/2026-10-22-companion-personality/evidence.json \
  --output /local-disk/eval/navigation-proof-new.json
```

验证器不执行证据中的基线源码；基线核对摘要与当时输出，当前实现重新计算。

真实模型使用[通用配置](../../../eval/README.md)。`--controls-only` 单测维度控制，`--examples-only` 单测示例边界，`--style-only --chat-suite transfer` 检查新话题。重评[冻结回复](artifacts/2026-10-22-companion-personality/personality-samples.json)使用 `--judge-existing`，不重新生成答案。

证据保留本轮 32 个带报告的阶段，包含开发失败、DNS 中断、跨代查询类型、重复窗口、工具引用转义、执行预算与评审协议问题；另记录未开始模型测试的脚本及 Unix socket 路径初始化失败。真实用户消息、账号凭据与运行日志未进入公开证据。

发行检查逐字核对 wheel 中 1141 个当前文件，新模块、前端资产及源码包来源记录均存在。常驻服务已更新，认证后的个性设置接口返回 200，Telegram 账号与轮询接入配置核对通过。原人物和记忆文件的修改时间均早于升级；已有个性及空闲配置保持默认，未自动开启主动联系。
